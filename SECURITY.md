# Security policy

## Supported version

Security fixes are applied to the latest commit on `main`. Older commits and
unreleased branches are not supported separately.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting form:

<https://github.com/androso/reader-monorepo/security/advisories/new>

Include affected routes or components, reproduction steps, impact, and any
suggested mitigation. You should receive an acknowledgement within seven days.
The maintainer will coordinate validation, remediation, disclosure, and credit
through the private advisory.

Never include real credentials, private books, user data, or production
database contents in a report. Use synthetic fixtures and redacted logs.
